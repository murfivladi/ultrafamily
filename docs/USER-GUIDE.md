# Руководство пользователя и администратора

Интерфейс доступен на русском и итальянском. Язык переключается в правом верхнем углу и сохраняется в профиле после входа.

## Публичный сайт

`/` показывает только явно опубликованные материалы. Публичная страница не содержит личных записей, документов, фотографий, метаданных участников, sitemap или RSS. Кнопка входа ведёт в закрытую платформу.

## Вход

1. Откройте `/login`.
2. Введите email и пароль или используйте демонстрационный аккаунт в development.
3. Новый участник может зарегистрироваться только по коду приглашения во вкладке «Приглашение».
4. После входа открывается `/dashboard`.

Если соединение потеряно, баннер явно сообщает, что изменения не сохраняются. Интерфейс не показывает ложного успеха.

## Главная панель

- Stat cards показывают участников, активные модули, общее число модулей roadmap и сессии.
- «Важное сейчас» объясняет, почему каждый элемент считается важным.
- Виджеты можно перемещать вверх/вниз и скрывать; порядок сохраняется в `user_preferences`.
- Кнопка «Настройка источников ленты» ведёт в настройки.
- Последние аудит-события и публикации показаны в виджете активности.

## Навигация

- Боковое меню: главная, каталог, пространства, настройки, сессии; администраторам платформы доступна админ-панель.
- Поиск в sidebar ищет модуль/функцию.
- Избранное и быстрые действия настраиваются в каталоге и настройках.
- На телефоне меню открывается кнопкой в topbar.
- Skip-link, видимый фокус и `aria`-подписи поддерживают клавиатуру и screen readers.

## Каталог модулей

Каталог содержит все модули ТЗ по внутренним этапам A–H:

- зелёный badge «Работает в основе» — только модули Этапа A;
- жёлтый badge «Запланировано» — дорожная карта, функциональность ещё не реализована;
- фильтры по группе, этапу и поисковому запросу;
- звёздочка добавляет или убирает модуль из избранного;
- переключатель активен только для модулей основы и только при праве `spaces:manage_access`.

Будущие модули показаны как прозрачная дорожная карта, а не как имитация готовых кнопок со скрытыми демонстрационными данными.

## Пространства и права

`/spaces` показывает доступные пространства пользователя, активную роль и участников активного домохозяйства. Владелец может:

- create a new household;
- create an invitation with role and expiration;
- inspect the role matrix for selected module/action;
- apply a point `allow`/`deny` override or return to role inheritance;
- grant/revoke access to sensitive modules.

Переключение пространства всегда проверяет membership на сервере. Гость по умолчанию не видит members and cannot mutate anything. Детский аккаунт не может приглашать участников or publish.

## Настройки

- Имя, язык и цвет аватара сохраняются через `/api/profile`.
- Три темы, light/dark, compact/comfortable density.
- High contrast, large text, reduced motion, economy and simplified UI modes.
- Favorites can be removed; dashboard widget order is preserved.
- All preferences are stored per account and validated server-side.

## Сессии

`/sessions` показывает активные устройства, last seen, expiration, hashed IP prefix and current session. Можно завершить отдельную сессию или все остальные; logout завершает текущую.

## Администрирование

`/admin` доступен только ролям `platform_owner` и `platform_admin`:

- users, platform roles, child flags and space counts;
- spaces and member counts;
- enabled module summary;
- recent audit events;
- hash-chain verification.

Администратор сервера — не владелец семейных данных: без membership он не может открыть участников и данные домохозяйства.

## Перед реальным использованием

Не вносите реальные медицинские, финансовые или детские данные, пока не настроены внешние encrypted backups, HTTPS/firewall, SMTP/2FA/passkeys, monitoring, legal review and full security/load testing. Stage A is an internal technical foundation.
